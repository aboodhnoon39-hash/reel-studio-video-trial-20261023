# جرّب معالجة فيديو قصير على خادم منفصل

ارفع فيديو، جهّز نسخة للمراجعة، ونزّل النتيجة. لكل مستخدم مساحة ورمز وصول منفصلان. مبني على Reel Studio، مع الحفاظ على ترخيص MIT ونسب العمل.

## التشغيل

ابنِ صورة الحاوية من Dockerfile الموجود في scripts/cloud-service. الخادم يستخدم Node.js وFFmpeg، ويستمع إلى PORT الذي تحدده الاستضافة. اضبط CLOUD_ADMIN_TOKEN بسر مستقل لا يقل عن 32 حرفًا من إعدادات الأسرار، واستخدم HTTPS.

في Render اختار Web Service وخطة Free فقط، وحدد مسار Dockerfile: scripts/cloud-service/Dockerfile. ملف render.yaml فيه إعدادات البداية، بدون أي مفاتيح.

## حدود التجربة

- حجم الرفع: 32 MiB، ومدة الناتج: حتى 60 ثانية.
- معالجة واحدة في كل مرة. ليست كل أدوات محرر سطح المكتب متاحة في هذه الخدمة.
- تخزين Render Free مؤقت: نزّل النتيجة فورًا، لأن الملفات قد تختفي عند إعادة التشغيل أو توقف الخدمة. التخزين الدائم يحتاج ربطًا منفصلًا.
- إنشاء مستخدم يحتاج سر الإدارة. الرفع والمعالجة والتنزيل يحتاجون رمز المستخدم في الترويسات، وليس في الرابط.
- لا يوجد تسجيل عام أو ربط متصفح من نطاق آخر. لا تضع أسرار الإدارة داخل واجهة عامة.

## واجهة الخدمة

GET /health يعرض حالة التشغيل.
POST /api/cloud/tenants ينشئ مساحة مستخدم؛ أرسل Authorization: Bearer مع سر الإدارة.
POST /api/cloud/upload?name=video.mp4 يرفع الملف.
POST /api/cloud/jobs يعالج الملف المرفوع.
GET /api/cloud/jobs?jobId=... يقرأ حالة المهمة.
GET /api/cloud/download?jobId=... ينزّل الناتج ويدعم HTTP Range.

طلبات المستخدم تحتاج x-tenant-id وx-tenant-token. احتفظ بهما خارج المستودع.
